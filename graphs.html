Where It Starts,
How Steep It Climbs

Every straight line on every exam paper is described by two numbers: where it crosses the y-axis, and how much it rises for each step to the right. Get those two and you can draw it, name it, compare it, and say what it means when the axes are rupees and kilometres instead of x and y.

Before you start: the five-minute gate

not marked · 8 items

Graphs questions are mostly lost on arithmetic with negative numbers, not on graphs. Type an answer and press Enter — the box checks itself. If you miss two or more, read the box underneath before going any further, because everything below assumes you can do these without thinking.

If you missed any of those

  • Coordinates are (across, up) — always x first. (−3, 2) is three left of the origin and two up. The four regions the axes make are called quadrants, and every one of them turns up on exam grids.
  • Substitute in brackets. For y = 7 − 3x at x = −2, write 7 − 3(−2) = 7 + 6 = 13. Writing 7 − 3 × −2 without brackets is how the sign goes missing.
  • Subtracting a negative adds. 7 − (−5) = 12. This is exactly the step inside the gradient formula, so it costs you marks in every lesson below if it is shaky.
  • Dividing a whole equation divides every term. 2y = 4x + 10 becomes y = 2x + 5, not y = 2x + 10. Lesson 4 depends on this one.
  • The equation pages are your fallback: Do It To Both Sides for rearranging, integers for negatives.

The line machine

Two dials: c, where the line crosses the y-axis, and m, how far it climbs for every one step right. Turn c and the line slides up and down without changing its slope. Turn m and it pivots about the point where it crosses the y-axis. That is the whole of y = mx + c, and you can see it before you read a word about it.

The function machine

Two operations, in order. The machine feeds in six inputs, writes the outputs, and plots every pair as a point. Notice two things as you play: the points always land in a straight line, and the line's gradient is whatever the machine ends up multiplying by. A function machine and a straight-line graph are the same object written two ways.

The formulas

straight line: y = mx + c  ·  m = gradient, c = y-intercept, crosses at (0, c)
find c: substitute a known point into y = mx + c and solve
x-intercept: put y = 0  ·  y-intercept: put x = 0
parallel lines ⇔ same gradient  ·  meeting point satisfies both equations
y = k is horizontal (m = 0)  ·  x = k is vertical (no gradient)

Drawing a graph: what the marker ticks

  1. A table with at least three x values. Two fix the line; the third catches your arithmetic.
  2. Each point plotted as a small cross, accurate to half a square.
  3. A single ruled line through all of them, across the whole range asked for — not stopping at your last point, not running past it.
  4. Axes labelled, and the scale read off the axis, not assumed to be one per square.
  5. If one point is off the line, the point is wrong, not the line. Recalculate it.

Interpreting a graph: the answer shape

  1. Gradient → “a rate of ___ (y-units) per ___ (x-unit)”. ₹12 per km, 30 litres per minute.
  2. Intercept → “the value of y when x is zero” said in context: the fixed charge, the starting amount.
  3. Flat section → nothing is changing. Steeper → changing faster.
  4. Where two lines cross → the one value of x where both give the same y. Below it one wins; above it the other does.
  5. Read values with dashed guide lines drawn to the axis. Examiners give a mark for the line.

Six traps

Read before any test

Reversing the operations but not the order

The inverse of “× 3 then + 5” is “− 5 then ÷ 3”. Writing “÷ 3 then − 5” undoes the right operations in the wrong order: from 35 it gives 6⅔ instead of 10. Unwrap it the way you would undo a parcel — the last thing done is the first thing undone.

Counting squares when the scales differ

If one square across is 2 units and one square up is 5, a line climbing 3 squares for every 2 squares across does not have gradient 1.5. It rises 15 for every 4, which is 3.75. Convert both sides of the triangle into the axis units before you divide. Read the numbers on the axes, never the squares.

Run over rise, or the sign dropped

Gradient is change in y on top. And the subtraction has to go the same way top and bottom: from (−2, 7) to (4, −5) it is (−5 − 7) ÷ (4 − (−2)) = −12 ÷ 6 = −2. A line falling from left to right must come out negative — if yours didn't, a sign went missing.

Reading c before the equation is in y = mx + c form

2y = 6x − 8 does not have gradient 6 and intercept −8. Divide every term by 2: y = 3x − 4. Likewise y = 5 − 2x has gradient −2, not 5 — the gradient is the number stuck to x, wherever it sits.

Answering about x when the question asked about the world

“The gradient is 12” scores nothing if the question says interpret it. “The fare goes up by ₹12 for each extra kilometre” scores the mark. A gradient in context is a rate, so it needs both units: rupees per kilometre.

Stopping at x when the question wanted a point

Where y = x + 2 meets y = −2x + 8, x = 2 is half the answer. The point is (2, 4). If a question says “coordinates”, “point” or “where do they meet”, it wants both numbers. Substitute back into both equations — if they disagree, you have found your error for free.
