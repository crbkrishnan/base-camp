Five traps
Read before any test

  

    
Picking a heading because of its size

      
The sentence students write: "I used h4 because I wanted smaller text." Headings are about structure, not size. <h1> is the title of the page, <h2> a main section, <h3> a part of a section. A screen reader and a search engine both read that outline, and a page that jumps from h1 to h4 has a hole in it. Choose the level by where it sits in the outline, then change the size with CSS.

      
Wrong
<h1>Rohan's Cricket Club</h1>
<h4>Fixtures</h4>

      
Right
<h1>Rohan's Cricket Club</h1>
<h2>Fixtures</h2>


    
Swapping href and src

      
The sentence students write: "I put src on the link and it did nothing." href points to somewhere you go, so it belongs on <a>. src names a file the browser must fetch and show right here, so it belongs on <img>. A link with no href is just text; an image with no src is a blank space. Related slip: <img> and <br> have no closing tag. Writing </img> is wrong.

      
Wrong
<a src="about.html">About</a>
<img href="logo.png" alt="Club badge">

      
Right
<a href="about.html">About</a>
<img src="logo.png" alt="Club badge">


    
Alt text that says nothing, or is missing

      
The sentences students write: alt="image", alt="photo1.jpg", or no alt at all. Alt text is what a blind visitor hears and what everyone sees when the picture fails to load. "Image" tells them there is an image, which they already knew. Describe what is in it, in about a short sentence. The mark scheme words are "describes the picture".

      
Wrong
<img src="team.jpg" alt="image">
<img src="team.jpg">

      
Right
<img src="team.jpg" alt="Eleven players in blue shirts holding a trophy">


    
CSS is American, and it is picky about punctuation

      
CSS is spelt color. Write colour and the browser ignores the line, with no error message, so the text just stays black and you think it is broken. Same for centre: the value is center. Then the punctuation: a colon between property and value, a semicolon after every value, and a different property for text (color) and what is behind it (background-color). Leave out one semicolon and the next line is swallowed as well.

      
Wrong
p { colour: red
    background-color: yellow; text-align: centre; }

      
Right
p { color: red;
    background-color: yellow; text-align: center; }


    
Treating width as the whole box

      
The sentence students write: "The box is 200 px wide, so it takes 200 px." In the default box model, width: 200px sets the content only. Padding and border are added on both sides, and margin too: 200 + 2×20 + 2×5 + 2×10 = 270. Two smaller slips come with it: the border adds to the size just like padding does, and padding is the gap inside the border (the background colour fills it) while margin is the gap outside (it never has a background).

      
Wrong
width 200 + padding 20 + border 5 = 225   (one side each, and no margin)

      
Right
200 + 2×20 + 2×5 + 2×10 = 270   (two sides of every layer)
